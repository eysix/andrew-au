# andrew-au

Andrew Au's portfolio site (v1): a single page with About, Work and Contact sections.
Plain HTML, CSS and a little JavaScript, with no build step.

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension. There is no JavaScript.

## Update content

- All the words live in `index.html` (look for `TODO` comments).
- Put your resume at `assets/andrew-au-resume.pdf`.
- Colours and fonts are CSS variables at the top of `style.css`.

## Deploy

Hosted on GitHub Pages: Settings → Pages → Deploy from a branch → `main`, `/ (root)`.
Every push to `main` redeploys the site.
